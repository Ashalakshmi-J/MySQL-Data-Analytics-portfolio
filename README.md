# MySQL Data Analytics Portfolio

Welcome to my database workspace! As an MSc IT graduate, this portfolio tracks my deep dive into engineering high-performance relational analytics queries using MySQL Workbench.

## 🛠️ Tech Stack & Skills Demonstration
- **Database Engine:** MySQL Server
- **Foundational SQL:** Filtering, String Patterns, Multi-column Sorting (`WHERE`, `LIKE`, `ORDER BY`)
- **Intermediate SQL:** Data Cleansing, Flow Control Logic (`IFNULL`, `GROUP BY`, `CASE WHEN`, `Subqueries`)
- **Advanced SQL:** Execution Performance, Reusable Routines (`CTEs`, `Window Functions`, `Stored Procedures`)

## 📂 Challenges Successfully Mastered

### 1. Foundational Queries
- Structured basic business parameters to extract records based on specific numeric and text matches.

### 2. Intermediate Operations
- Implemented `IFNULL` logic to standardize missing fields into actionable values.
- Formulated conditional multi-tiered columns using `CASE WHEN` to slice customer financial segments.
- Overcame SQL order-of-operation constraints using nested `Subqueries` to evaluate aggregate performance indicators.

### 3. Advanced Solutions
- Engineered targeted tracking arrays using analytical window functions (`DENSE_RANK() OVER`).
- Modularized complex nested dependencies into highly legible virtual tables using Common Table Expressions (`WITH` CTE architecture).
- Programmed reusable backend routines by compiling dynamic parameter-driven `Stored Procedures`.
